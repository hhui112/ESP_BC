# 盛和养老固件 V2.3.5 更新说明

**基准版本：** V2.3.4（`BC_ESP_2026_2_3_4`）  
**本版版本号：** `BC_ESP_2026_2_3_5`（当前最新）

本版在 V2.3.4 涂鸦 MQTT / 板端 OTA 之上，增加**云端给 SU2 传感器做 OTA**，并删除 BLE 传感器升级通道。日常 5s/60s/睡眠报告 JSON、UART 通信栈不变。

---

## 一、云端传感器 OTA（新增）

MQTT `/ota/device/upgrade` 按下发 `version` 分流：

| 云端 version | 行为 |
|--------------|------|
| 以 `SU2` / `SU3` 开头 | 传感器通道：HTTPS 下载 → UART port4 刷写 |
| 其它（如 `BC_ESP_...`） | 原板端 `esp_https_ota` |

流程：

1. HTTPS 下载到 PSRAM（上限 1MB）；下载前暂停 MQTT TLS，下完再恢复
2. `set mode 3` → 停日常 UART → port4 清盘 `0x00` / 128B 分包 `0x01` / 结束 `0x02`
3. 云端**一推就刷**，不做「当前版本 ≥ 目标则跳过」
4. progress / inform 使用 `module=sensor`

---

## 二、版本上报

Topic：`/ota/device/inform/{productKey}/{deviceId}`

| 时机 | module | version 示例 |
|------|--------|----------------|
| MQTT 连上 | `default` | `BC_ESP_2026_2_3_5` |
| UART 读到 `version` 后 | `sensor` | `SU2_1_9_4_Board_1`（由 `SU2-1.9.4,Board:1.0` 转换） |

---

## 三、删除 BLE 传感器 OTA

已删除：`type:5` + `sensorUpgrade`、`0xBB 0xCC` 透传、`0x33 0x44 0x55`。  
保留：BLE 配网、`type:4` 查版本、床控 `type:12`。

---

## 四、稳定性

port4 刷写 ACK 改为短超时轮询，避免每包空等 800ms（约 1000 包从十几分钟降到可量产时长）。下载 / 刷写按每 1% 打日志。

---

## 五、云端 / 产线注意

1. **必须先把板端升到本版**，再下发传感器包；旧板端会把 `SU2...` 当板端 OTA 去刷，会失败。
2. 涂鸦产品需增加 OTA 模块名 **`sensor`**；传感器包 version 必须以 **`SU2`** 开头。
3. 量产烧录文件见本目录：`bootloader.bin` / `partition-table.bin` / `ota_data_initial.bin` / `bochuang-program.bin`。云端板端 OTA 用 `BC_ESP_2026_2_3_5.bin`。
