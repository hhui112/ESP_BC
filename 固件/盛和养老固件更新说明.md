# 盛和养老固件说明

**当前最新：V2.3.5 / `BC_ESP_2026_2_3_5`**  
烧录包：`固件/V2.3.5/`（含 bootloader、分区表、ota_data、应用程序；云端 OTA 用 `BC_ESP_2026_2_3_5.bin`）

**盛和养老固件 V2.3.5（当前最新）**

V2.3.4 基础上增加云端传感器 OTA，删除 BLE 给 SU2 的升级通道。

新增：

​	1、云端 `/ota/device/upgrade`：`version` 以 `SU2`/`SU3` 开头则 HTTPS 下载后经 UART port4 刷传感器；否则仍走板端 OTA

​	2、下载前暂停 MQTT TLS，刷写走 `set mode 3` + 清盘/128B 分包/结束；云端一推就升级，不按版本号跳过

​	3、上电/MQTT 连上报板端版本 `module=default`；读到 UART `version` 后再报传感器 `module=sensor`（如 `SU2_1_9_4_Board_1`）

删除：

​	BLE 传感器 OTA（`sensorUpgrade` / `0xBB 0xCC` 透传 / `0x33 0x44 0x55`）；配网、查版本、床控保留

修复：

​	port4 ACK 短超时轮询，避免每包空等导致刷写过慢

云端注意：

​	先升板端到本版，再推传感器包；OTA 模块名必须为 `sensor`，包 version 以 `SU2` 开头

固件版本号:
    BC_ESP_2026_2_3_5

**盛和养老固件 V2.3.4**

V2.2.4 基础上迁移涂鸦 MQTT、优化板端 OTA，并修复 60s 上报频率。明细见 `固件/V2.3.4/BC_ESP_2026_2_3_4更新说明.md`。

修改：

​	1、Broker 改为 `mqtts://iot.smartbed.ink:1883`；SNTP 完成后再签 MQTT

​	2、每次 MQTT 连上都 inform 板端版本；OTA URL 扩至 1024；下载前暂停 MQTT

​	3、5s/60s 增加 `sensor_ts`；`UP_RATIO_60S` 改为 12（约 1 分钟一条）

固件版本号:
    BC_ESP_2026_2_3_4
